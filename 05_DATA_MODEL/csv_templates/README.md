# CSV Templates

These templates are draft only.

They are for Phase 2 manual/CSV testing of the approved v4 intake specification:

- `../V4_INTAKE_SPECIFICATION.md`

## Templates

- `WF0_erank_keyword_intake_template.csv`
- `WF1_everbee_alura_product_intelligence_template.csv`
- `WF2_apify_live_snapshot_template.csv`
- `manual_opportunity_review_template.csv`

## Rules

- These files contain headers only.
- These templates are for manual/CSV testing only.
- These templates do not approve database schemas.
- These templates do not approve n8n workflows.
- These templates do not approve scoring.
- These templates do not approve external service usage.
- Real export fields from eRank, EverBee, and Alura still need to be compared against these headers before finalization.

## Blocked

Do not use these templates to justify:

- creating database tables,
- creating n8n workflows,
- scraping dashboards,
- running Apify,
- calling paid APIs,
- building WF3 scoring,
- generating product concepts,
- touching Printify,
- creating Etsy drafts,
- publishing Etsy listings.
