# Field Trust Rules

## Never Treat Estimates As Truth
EverBee/Alura/eRank values are directional until proven by your own Etsy stats.

## Always Store Source
Every number should record where it came from.

## Scoring Eligibility
A field is scoring-eligible only if:
1. source is known,
2. meaning is understood,
3. confidence is set,
4. user approves it for scoring.
