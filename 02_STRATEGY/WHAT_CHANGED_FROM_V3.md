Apify was the first core data source.

Problem: basic scraped Etsy fields were too weak for winner detection.

## v4

- trying to infer product winners from basic scrape fields
- building scoring immediately after WF1

## Preserved
- n8n as orchestration tool
- controlled testing discipline
- Source of Truth approach
- no auto-publishing
- no copycat products
- learning engine goal
